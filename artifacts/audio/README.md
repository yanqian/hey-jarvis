# Local audio artifacts

This directory is the local-only home for retained audio used by experiments
and Realtime evaluation. Audio files are intentionally ignored by Git because
they may contain personal voice recordings.

`fixtures/` contains the one canonical replay WAV for each Realtime scenario.
The original recordings used to make these short replays belong outside the
repository and are not required for normal evaluation runs.

Product voice assets live under `assets/` and are managed separately.
