# F135 Fast Coding Evidence

FAST_CODING_EVIDENCE: F135
CODING_PASS: F135

## Scope

Persist F134's already-sanitized Realtime negotiation failure summary in the
packaged app's bounded diagnostics without reading WebKit capability material or
retaining provider content.

## Implementation

- Added an optional coordinator negotiation-failure sink invoked only after the
  existing F134 validation step. Sink exceptions are non-fatal and cannot block
  the existing stop/cleanup path.
- Wired the packaged sidecar to write `hey-jarvis-realtime-v1` records containing
  only local/upstream HTTP status and bounded error type/code.
- Reused the existing 512 KiB / three-generation rotation boundary and added a
  lock so health and HTTP event writes cannot interleave.
- Added structured support-export validation that accepts safe diagnostic names
  such as `invalid_api_key` while rejecting secret-shaped `sk-...` / `ek_...`
  values, unknown fields, messages, and other content-bearing records.
- Documented the persisted summary and privacy boundary.
